## 발단

사용자가 `/rein:persona` 를 인자 없이 호출 → 선택 목록에 "새로 만들기" 가 없어 커스텀 생성에 도달할 수 없음을 발견. 이어서 다른 프로젝트의 실사용 화면을 제보 — 보스 에이스 → 제니 전환 직후 이름을 "지니"로 오독, 호칭이 직전 프리셋의 "보스"로 유지, 인사말을 요약만 보고 창작.

## 근본 원인 2건 (둘 다 이번에 봉합)

1. **세션 중 전환 시 본문 미갱신** — 캐릭터 본문은 세션 시작 훅이 1회 주입할 뿐이고, 매 턴 들어가는 것은 `활성 프리셋: <이름> — <요약>` 1줄뿐(`get_turn_brief()`). 전환해도 직전 본문이 남아 요약과 섞인다. 증상 3종이 이 하나로 설명됨.
2. **로더 호출 형태가 환경변수 존재를 전제** — 스킬 문서가 `${CLAUDE_PLUGIN_ROOT:-plugins/rein-core}/…` 형태로 호출하는데, 스킬의 명령 실행 환경에 그 변수가 **없다**(2026-07-27 실측). 스크립트 파일은 fallback 으로 찾아지지만 로더 내부 경로 해석이 실패해 **오류 없이 빈 출력**을 반환 → 호출자가 "인사말 없음"으로 오해해 즉석 창작. 인사말 창작의 직접 원인.
   - 실측: 변수 없이 `--persona-greeting jennie` → 빈 출력 / 변수 주면 정상 문구. `--persona-file` 도 동일.

## 변경 요약 (5건)

1. 선택 목록에 **새로 만들기** 고정 옵션 추가 (끄기와 함께 실존 프리셋 수와 무관한 고정 2종)
2. **선택지 상한 4개** 명문화 — 총 4 이하 단일 질문 / 5 이상 2단 제시(갈래 → 갈래 내 목록), 갈래 내 4 초과 시 `다음 목록 보기` 로 이어보기, 갈래 항목 1개면 `뒤로 가기` 동반(최소 2개 제약), **도달 가능성 불변식**(상한 때문에 후보 누락 금지)
3. **전환 즉시 본문 반영** 단계 신설 — 기록 직후 로더가 해석한 경로 + 불변층을 읽어 그 턴부터 적용. 요약으로 이름·호칭 추측 금지, 빈 출력이면 호출 의심 후 1회 재시도, 실패 시 추측 말고 중립 보고. 끄기는 직전 말투 즉시 폐기
4. **로더·lint 호출 규약** 신설 — plugin 루트를 스킬 자기 위치(base directory 의 `../..`)에서 유도해 `CLAUDE_PLUGIN_ROOT` 로 명시 전달. 셸 상태가 호출 간 유지되지 않으므로 예시 4곳 전부 `PR=` 정의 동반. 빈 출력을 "비활성"으로 오해 금지 — 내장 프리셋이 비면 호출 결함이므로 창작 금지
5. **인사말 후보 선택** — 생성 흐름 초안 확인 단계에서 후보 2~3개 제시 + `직접 쓸게요` 경로. 7문항 세트·8번째 질문 부재 불변식은 그대로 유지(제시는 확인 단계 소속)
