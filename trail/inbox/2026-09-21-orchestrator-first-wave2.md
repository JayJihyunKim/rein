# 2026-09-21 — 메인 세션 지휘 기본화 구현 3/4: 세션 시작 배선 + 이 저장소에서 기능 켜기

## 한 것

계획 `docs/plans/2026-09-21-orchestrator-first-default.md` 의 Phase 2 / Task 2.1(`inject-wiring`)을 편집 전용 단독 워커로 실행하고 메인 세션이 점검·리뷰·커밋했다. 실행 중인 훅을 고치는 안전 민감 변경이라 워커 모델은 세션 모델 그대로 — 지휘자 판단.

- `plugins/rein-core/hooks/session-start-rules.sh`: 저장소의 `.rein/policy/rules.yaml` 이 `orchestrator-first: {enabled: true}` 일 때만 지휘 규칙 요약을 작업 순서 규칙과 라우팅 표 사이에 주입. 기존 규칙 6종 for 줄 리터럴은 그대로 두고 루프 본문을 `append_rule` 함수로 뽑았다. 헤더 주석의 규칙 수·크기 서술 갱신.
- 켜짐 판정(최종): `python3 "$LOADER" --rule-enabled orchestrator-first 2>/dev/null | cmp -s - <(printf 'true')` — 로더 종료 코드 0 **그리고** stdout 이 바이트 단위로 `true` 일 때만 켜짐. 훅 상단의 `set -euo pipefail` 이 로더 비정상 종료를 파이프라인 실패로 만들고, `if` 조건 안이라 훅이 죽지 않는다.
- 신규 `tests/hooks/test-orchestrator-first-emit.sh`: 켜짐 1개(마커 제자리 + 요약 648B ≤ 1,000B + JSON 한 줄 9,212자 < 10,000) + 꺼짐 경계 8개(정책 없음, 깨진 정책, "true" 출력 뒤 비정상 종료, 대소문자 다른 답, 끝 개행, 중간 NUL, 빈 답, 로더 없음). `set -eo pipefail`.
- `tests/hooks/run-all.sh` 에 새 테스트 두 개 등록, `.rein/policy/rules.yaml` 에 두 줄 추가로 이 저장소에서 기능 켬. 이 저장소에서 훅 출력 7,988자 + 마커 포함 확인. 다음 세션 시작부터 주입된다.
- `.claude/agents/` 미생성 확인(오버레이 회귀가드).

## 리뷰

코드 리뷰 3회 — 수정 필요(647초) → 수정 필요(946초) → 통과(1,037초). 두 지적 모두 계획에 적힌 코드 자체의 허점이었고 방향은 같았다(fail-closed 계약을 더 엄밀하게).

1. 높은 등급: 로더가 "true" 를 출력한 뒤 비정상 종료해도 켜짐 — 계획의 코드가 `|| true` 로 종료 코드를 버렸다. 계획과 앞 단위 보안 검토 의견("종료 코드 말고 stdout 을 볼 것")은 구버전 로더(exit 0 + 빈 답)만 염두에 뒀다. → 종료 코드 0 **그리고** 정확한 답.
2. 높은 등급: 명령 치환이 끝 개행을 지워 "true" + 개행도 켜짐. 중간 등급: 테스트 파이프가 훅의 종료 코드를 가림. → 명령 치환을 없애고 `cmp` 바이트 비교(같은 부류인 NUL 제거도 함께 막힘), 테스트에 `pipefail`.
- 회차마다 고치기 전 훅에서 재현되고 고친 훅에서 막히는 것을 같은 가짜 로더로 확인한 뒤 재요청했다. 2·3회차는 후속 요청서 양식 — 종결 칸에 적은 1회차 지적은 되돌아오지 않았고, 범위 밖 새 탐색 지적도 없었다.

보안 리뷰: 통과, 차단급 없음(표준 강도), 통과 기록 발급. 검토자가 실물 훅을 임시 픽스처에서 돌려 추가 경계(`cmp` 부재, "true" + 대량 출력으로 인한 SIGPIPE, 출력 후 강제 종료, stderr 에만 "true", 앞 공백, 끝 CR, 로더 구문 오류)에서도 전부 꺼짐 + 기존 6종 유지 + 훅 종료 코드 0 을 확인. 정보성 참고 3건(수정 요구 아님): 프로세스 치환은 이 훅 파일에서는 처음이지만 `hooks/lib/` 에 기존 사용처가 있다 / 새 테스트가 프로젝트 경로 덮어쓰기 환경변수를 비우지 않는 것은 형제 테스트와 같은 관행 / `/tmp` 하드코딩. `python3` 가 없으면 훅이 죽는 것은 변경 전에도 같았다(회귀 아님).
