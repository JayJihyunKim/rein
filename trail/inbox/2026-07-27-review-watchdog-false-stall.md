## 발단 — 직전 사이클에서 실증된 오판

페르소나 작업의 코드 리뷰가 6분에 강제 종료됐다. 사후 분석 결과 codex 는 멈춘 게 아니라 **우리 테스트가 끝나기를 기다리는 중**이었다.

## 근본 원인

생존 판정이 **결합 출력 성장 단일 축**이었다. codex 는 자식 명령 실행 **동안 출력을 내지 않고** 완료 시점에 일괄 방출하므로, 리뷰어가 테스트를 돌리면 그 소요만큼 성장이 정확히 0 이 된다.

실측: 실패한 리뷰의 마지막 동작이 `bash tests/skills/run-all.sh`(당시 219초, 현재 258초) 실행이었고 종료 시각은 elapsed=360초(=300 상한 + 60 무성장). 별도 SPIKE(`sleep 60` 지시)에서 출력은 604바이트에 45초 이상 정지, 자손 프로세스는 1→3 증가, 로그에는 시작 표식만 있고 완료 표식은 명령 종료 후 등장.

→ **리뷰어가 성실히 검증할수록 죽는 역-인센티브.** 과거 사이클의 "codex timeout" 기록도 상당수 동일 원인일 가능성 (재해석은 후속).

## 변경 요약

1. **생존 신호를 3축으로 확장** — 출력 성장(기존) + 미완료 자식 명령 표식 + 자손 프로세스 활동.
2. **edge / level 구분 + 유한 lease** — 창 사이 실제 변화(출력 성장·자손 PID 집합 변동)는 **edge** 로 무기한 유예(기존 계약 유지). 상태만 유지되는 **level**(미완료 표식·자손 존재)은 기본 20창 lease 안에서만 유예하고 소진 후 정지 계수 재개. *이 구분이 없으면 표식만 남긴 hang 이 영구 생존한다 — 리뷰 1회차 High 지적.*
3. **정지 임계 2창(60초) → 6창(180초)** — 자식도 출력도 없는 순수 추론 구간 보호(사용자 결정).
4. **기준선은 불변 상수 0** — 관측값으로 잡으면 상한 전에 시작된 장기 자식이 기준선에 흡수돼 축이 영구 침묵한다(설계 리뷰 High).
5. **시작 표식 판정을 명령행 구조 인식으로** — 절대경로 프로그램으로 시작 + 작업 디렉토리 절 포함. 산문 오인은 막고 공백 있는 경로는 허용.
6. **진단 문구**를 모든 종료 경로에서 참인 형태로 교체. 호출자 판별용 라인 앵커는 불변.
7. **override 3종 → 5종**(정지 임계·lease 추가), 경고 문구에 단위 라벨.

- **실전 검증**: 수리 후 이 사이클의 리뷰 12회 전부 정상 완주, **정지 오판 0건**. 그중 다수가 15~19분 소요 — 예전 코드였다면 6분에 죽었을 리뷰들이다.
- 환경 의존: 자손 관측이 불가한 격리 환경에서는 해당 축 검증 4건이 명시적 skip(전제 불충족). 결정론 seam(W17)이 그 공백을 환경 비의존으로 메운다.
