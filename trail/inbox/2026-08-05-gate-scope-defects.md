## 공통 뿌리와 수리

세 결함 모두 어휘적 판정(문자열/표식 존재)을 의미적 판정(현재 저장소·현재 작업에
실제 영향)으로 취급했다. 필요한 패턴(경로 소속 검사·절 형태 검증)은 저장소에 이미
있었고, 수리는 발명이 아니라 연결이었다.

1. **저장소 경계** (`pre-edit-dod-gate.sh`): 리뷰 표식의 대상 경로를 전부 물리
   정규화(realpath)로 판정 — 저장소 밖(타 저장소 문서·저장소 안 symlink 가 밖을
   가리키는 경우 포함)이면 판정 제외 + 비차단 경고. 표식 파일은 삭제하지 않음.
2. **작업 관련성** (같은 파일): 미리뷰/stale 문서는 **선택된 활성 작업 기준서**
   (선택기 결과 우선, 특정 불가 시 전 활성 폴백)가 참조(본문 상대경로/파일명,
   또는 plan ref 문서 — 참조값은 첫 토큰만)할 때만 차단. 무관 문서는 경고 강등.
   말뭉치 1회 수집 캐시로 표식당 비용 grep 2회. tests/ TDD 면제 유지.
3. **문자열 vs 실행** (`git-subcommand-model.sh` + 쌍둥이 매처 + 커밋 게이트):
   - heredoc **본문** 소거(매칭 입력에만) — 인용(줄 넘김 지속)/워드 시작 주석/
     산술 `((...))` 인지 문자 스캐너, 인용 종결자 검증·소비, 미종결 fail-closed.
   - 샌드박스 커밋 면제 — 좁은 형태 계약 전부 충족 시만: 한 줄, `&&` 만(그 외
     구분자·backtick·`$`·`<` 전무, 인용 불문), 첫 절 리터럴 절대경로 cd, 후속
     이동(cd/pushd/popd) 금지, `-C`/`GIT_DIR` 계열 토큰 전무, python realpath
     물리 검증 + **연결형 워크트리 판별**(.git 파일의 gitdir 이 이 저장소를
     가리키면 면제 불가) 최종 관문. 실패는 전부 면제 없음(fail-closed).
   - 3게이트(coverage/리뷰 표식/커밋 메시지 포맷) 공유 면제 + NOTICE 방출.
   - 기존 보안 케이스 `cd /other && git commit`(구: 무조건 차단)은 사용자 확정
     계약으로 재분류 — 변수 cd 등 증명 불가는 fail-closed 유지.
