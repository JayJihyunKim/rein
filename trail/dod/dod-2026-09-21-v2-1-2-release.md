## 배경 / 등급

지휘 기본화 구현이 사용자 대면 변화를 만들었다 — 저장소의 `.rein/policy/rules.yaml` 에 `orchestrator-first: {enabled: true}` 를 넣으면 세션 시작에 지휘 규칙 요약이 주입된다(기본 꺼짐), `rein:orchestrator` 에이전트 설명이 "기본 진입점" 에서 "명시 호출 옵션 경로" 로 바뀐다, Builder 에이전트 세 개의 완료 기준이 단독 실행 / 워커 dispatch 를 구분한다, 작업 기록 형식에 선택 필드 두 개가 생긴다.

등급 **patch (2.1.2)** — 사용자 결정(2026-09-21 "패치수준 업데이트로"). 버전 규칙 Rule A 의 표를 문자 그대로 읽으면 새 opt-in 규칙은 "신규 기능 → minor" 후보다. 사용자가 patch 로 정했다 — 근거로 삼을 수 있는 사정: 기본 꺼짐이라 opt-in 하지 않은 사용자에게는 세션 동작 변화가 없다. Rule A 에 명문화된 예외(차단 범위 확대의 강등)에 해당하는 경우가 아니라 v2.0.3 과 같은 일반 사용자 override 다. Rule B: 오늘 main 머지 없음(직전 09-08~09 v2.1.1).
