## 배경

`/rein:persona` 를 인자 없이 호출하면 선택 흐름으로 붙는데, 그 선택 목록은 `내장 프리셋 + 실존 커스텀 + 끄기(중립)` 로만 구성된다. **생성 흐름(7문항 Q&A)은 구현되어 있으나 선택 목록에 입구가 없어**, 사용자가 명령만 치면 커스텀 생성에 도달할 방법이 목록상 존재하지 않는다 (2026-07-27 사용자 실사용 중 발견).

동시에 잠재 결함 1건: AskUserQuestion 의 선택지는 **최대 4개**(도구 스키마 `options.maxItems: 4`)다. 현행 후보 수는 내장 2 + 끄기 1 = 3 으로 상한 이내지만, 커스텀이 2개만 생겨도 5개가 되어 상한을 넘는다. 여기에 "새로 만들기" 를 더하면 **커스텀 1개부터** 넘친다 — 입구만 추가하면 "만드는 순간 목록이 깨지는" 상태가 되므로 두 건을 한 사이클로 묶는다 (사용자 결정, 2026-07-27).

## 범위

1. **선택 목록에 "새로 만들기" 고정 옵션 추가** — 선택 흐름 후보 수집에 고정 옵션으로 상시 포함. 선택 시 persona.yaml 을 쓰지 않고 생성 흐름으로 인계한다.
2. **선택지 상한(4개) 초과 처리 규칙 명문화** — 후보 총수 ≤4 면 단일 질문, ≥5 면 2단 제시(갈래 선택 → 갈래 내 목록). 갈래 내 항목이 상한을 넘으면 마지막 자리를 "다음 목록 보기" 로 이어간다. **상한 때문에 실존 후보가 조용히 누락되지 않아야 한다**(도달 가능성 불변식).
3. **인계 시 인사말 단계 미수행 명문화** — "새로 만들기" 로 인계된 시점엔 바뀐 상태가 없으므로 전환 인사말을 내지 않는다. 인사말은 생성 흐름 끝의 "지금 적용할까요?" 에서 실제 활성화될 때 낸다.
4. **[버그] 전환 즉시 본문 반영** — 세션 도중 페르소나를 바꿔도 캐릭터 본문이 다시 로드되지 않아, 직전 프리셋 본문 + 신규 요약 1줄이 섞인 상태로 응답하던 결함. 기록 직후 로더가 해석한 소스 경로에서 신규 본문(불변층 + 프리셋)을 읽어 **그 턴부터** 적용하도록 명문화. 요약 1줄로 이름·호칭을 추측하는 것을 금지한다.
5. **인사말 후보 제시 + 직접 작성** — 생성 흐름의 초안 확인 단계에서 인사말 후보 2~3개를 제시하고 사용자가 고르거나 직접 쓰게 한다. **7문항 세트는 불변**(8번째 질문 신설 금지) — 제시는 확인 단계의 일부다.
6. **회귀 테스트 추가** — 위 5건을 정적 계약으로 고정.

### 배경 보강 — 4번 항목 (2026-07-27 사용자 실사용 제보)

다른 프로젝트에서 보스 에이스 → 제니 전환 직후: 이름을 "지니"로 오독, 호칭이 직전 프리셋의 "보스"로 유지, 인사말을 요약만 보고 즉석 창작. 근본 원인 = 캐릭터 본문은 세션 시작 훅이 1회 주입할 뿐이고, 매 턴 주입되는 것은 `활성 프리셋: <이름> — <요약>` 1줄뿐(`get_turn_brief()`)이므로 **세션 중 전환은 본문이 갱신되지 않는다**. 증상 3종이 모두 이 하나의 원인으로 설명된다.

### 범위 외

- 로더·훅·lint 스크립트 변경 없음 (선택 UX 는 스킬 문서 계약이 전부이며 실행 코드 경로가 아님). 4번 항목도 **로더의 기존 `--persona-file` 출력을 소비**할 뿐 로더·훅을 고치지 않는다 — 매 턴 본문 전체를 재주입하는 방식은 훅당 주입 예산을 매 턴 소모하므로 채택하지 않는다.
- README / 첫 세션 안내 문안 변경 없음 — 두 채널 모두 이미 "질문 몇 개로 나만의 캐릭터를 만들 수 있다" 를 안내하고 있어 추가 안내가 불필요(2026-07-27 실측).
- 7문항 세트의 순서·개수 변경 없음 (기존 불변식 유지).

## 검증 기준

- [ ] 선택 목록에 "새로 만들기" 가 고정 옵션으로 명시된다.
- [ ] 선택지 상한 4개와, 초과 시 2단 제시(갈래 → 목록) + 4개 초과 갈래의 이어보기 규칙이 문서에 있다.
- [ ] "상한 때문에 후보가 누락되지 않는다" 는 도달 가능성 불변식이 명시된다.
- [ ] "새로 만들기" 선택 시 persona.yaml 미기록 + 생성 흐름 인계 + 인사말 미수행이 명시된다.
- [ ] `### 적용 질문` 의 "예" 분기가 기록 + 인사말 수행을 모두 포함한다.
- [ ] 전환/재선택 시 로더가 해석한 경로에서 신규 본문을 읽어 그 턴부터 적용하는 단계가 명시된다. 요약 1줄로 이름·호칭 추측 금지 + 해석 실패 시 추측 금지(중립) + 끄기 시 직전 말투 즉시 폐기가 함께 명시된다.
